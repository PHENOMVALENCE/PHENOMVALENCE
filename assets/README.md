# Profile Assets

Local media used by `README.md`. Keep paths relative (`./assets/...`) so GitHub renders them reliably.

## Structure

```text
assets/
├── banner.png              # Hero banner (recommended ~1280×420, <100KB)
├── profile.png             # Circular avatar / headshot
├── project-images/         # Featured project screenshots
│   ├── hanzo-marketplace.png
│   ├── crosslife-lms.png
│   ├── digital-town-square.png
│   ├── bossify-academy.png
│   ├── m-grid.png
│   ├── digital-economy-africa.png
│   └── portfolio-website.png
└── README.md
```

## Guidelines

| Asset | Size tip | Format |
|-------|----------|--------|
| `banner.png` | 1280×420 | PNG (or JPG/WebP) |
| `profile.png` | 400×400 | PNG (square) |
| Project images | 800×420 | PNG / JPG |

Replace placeholder project images with real screenshots. Keep filenames the same unless you also update links in `README.md`.

See [docs/PROFILE_GUIDE.md](../docs/PROFILE_GUIDE.md) for full update instructions.
